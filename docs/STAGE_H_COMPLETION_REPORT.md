## 🎯 功能特性

### 1. 系统总览页面 📊
- **统计卡片**: 总文档数、总Chunk数、Collection数、系统状态
- **Collection统计表**: 实时显示各Collection的文档和Chunk数量
- **API集成**: `/api/stats/overview`, `/api/stats/collections`

### 2. 文档浏览器 📄
- **文档列表**: 展示所有已摄取的文档
- **表格视图**: 文档名、Collection、Chunk数、创建时间
- **操作功能**: 删除文档（带确认）
- **空状态**: 友好的空状态提示
- **API集成**: `/api/documents`, `/api/documents/{id}`

### 3. 文档摄取管理 ⬆️
- **文件上传**: 支持点击和拖拽两种方式
- **多文件上传**: 批量上传多个PDF文件
- **Collection配置**: 可选择目标Collection
- **进度显示**: 实时进度条和状态文本
- **结果反馈**: 成功/失败详细信息
- **API集成**: `/api/ingest`

### 4. 查询测试页面 🔍
- **查询参数**: 问题输入、Top-K配置、Reranker开关
- **结果展示**: 答案内容、检索文档列表
- **交互友好**: 即时反馈、清晰布局
- **API集成**: `/api/query`

### API集成
| API端点 | 方法 | 用途 | 集成页面 |
|---------|------|------|----------|
| `/api/stats/overview` | GET | 系统统计 | 系统总览 |

## 🚀 使用指南

### 启动Dashboard
1. 启动Spring Boot应用: `mvn spring-boot:run`
2. 访问: `http://localhost:8080/`
3. 自动重定向到: `http://localhost:8080/dashboard`

### 功能演示
```bash
# 1. 查看系统总览
访问首页即可看到系统统计信息

# 2. 上传文档
点击"文档摄取" → 拖拽或选择PDF文件 → 自动上传

# 3. 浏览文档
点击"文档浏览器" → 查看所有已摄取的文档

# 4. 测试查询
点击"查询测试" → 输入问题 → 执行查询
```
